# 학급 벌금 / 법무 관리 시스템

Next.js (App Router) + Supabase 로 만든, 실제 배포 가능한 학급 벌금 관리 웹앱입니다.

## 기능

1. 관리자(반장/부반장/법무부장)가 수면·지각 벌금을 부과
2. 청소 현황에서 불참 체크 → 청소 벌금 자동 생성 (DB 트리거)
3. ~~수면 벌금: 교시(복수)·횟수·증거 사진 업로드, 금액 자동 계산~~
4. 학생은 본인 벌금·납부 기한·계좌·2배 인상 시점 확인
5. 잘못 부과한 벌금은 소프트 삭제(사유 기록, 추적 가능)
6. 학생이 여러 건을 묶어 입금 영수증과 함께 신청 → 관리자가 통장 대조 후 승인



## 운영 메모

- 일반 학생 추가는 로그인한 관리자가 **학생 관리** 화면에서 가능, 최초 가입시 학생 스스로 정보를 기입해 가입 가능
- 첫 관리자만 SQL(seed)로 직접 등록해야 함 (RLS가 비관리자의 명단 수정을 막으므로)
- 벌금 종류는 지각 / 청소불참 2종 고정
